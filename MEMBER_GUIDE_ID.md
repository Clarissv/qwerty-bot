# 🎮 Panduan Member - Cara Membeli Slot Server

## Selamat Datang!
Panduan ini akan membantu Anda membeli slot server dan bergabung ke server game yang sudah di-boost melalui bot Discord kami.

---

## 🛒 Cara Membeli Slot

### Langkah 1: Cari Member Panel
Cari pesan **Member Panel** di channel pembelian yang sudah ditentukan. Tampilannya seperti ini:

```
🛒 Member Panel
━━━━━━━━━━━━━━━━━━━━━

Gunakan dropdown di bawah untuk membeli slot atau melihat informasi server.

Purchase Slots: Pilih server untuk membeli slot
Server Info: Lihat detail dan daftar member
```

---

### Langkah 2: Pilih Server
Klik dropdown **"🛒 Purchase Slots"** dan pilih server.

**Yang akan Anda lihat:**
- Server 1 - X/20 slot | IDR 20.000 | Pending/Active

**Keterangan:**
- **X/20 slot**: Berapa banyak slot yang terisi (maksimal 20)
- **IDR 20.000**: Harga per slot
- **Pending**: Boost belum diaktifkan
- **Active**: Boost sedang berjalan

---

### Langkah 3: Masukkan Jumlah Slot
Setelah memilih server, akan muncul modal (popup):

```
📝 Berapa Banyak Slot?
━━━━━━━━━━━━━━━━━━━━━

Masukkan jumlah slot yang ingin Anda beli (1-20)
```

**Masukkan angka** antara 1 sampai slot yang tersedia.

**Contoh:**
- Jika server menunjukkan **5/20**, Anda bisa beli hingga **15 slot**
- Masukkan `3` untuk membeli 3 slot

Klik **Submit**

---

### Langkah 4: Masukkan Username Roblox
Selanjutnya, akan muncul modal lain:

```
📝 Masukkan 3 Username Roblox
━━━━━━━━━━━━━━━━━━━━━

Masukkan 3 username (satu per baris)
```

**Penting:**
- Masukkan **tepat** sesuai jumlah username yang Anda tentukan
- Satu username per baris
- Gunakan username Roblox yang tepat (case-sensitive)

**Contoh:**
```
PlayerOne
CoolGamer123
ProPlayer99
```

Klik **Submit**

---

### Langkah 5: Konfirmasi Pembelian
Anda akan melihat pesan konfirmasi:

```
📝 Konfirmasi Pembelian Anda

Anda telah memilih 3 slot untuk Server 1.

Server: Server 1
Harga per slot: IDR 20.000
Total: IDR 60.000

Anda perlu menyediakan 3 username Roblox
```

**Periksa dengan teliti, lalu klik:**
- ✅ **Confirm** - Lanjutkan pembelian
- ❌ **Cancel** - Batalkan dan mulai ulang

---

### Langkah 6: Tiket Berhasil Dibuat! 🎉
Setelah konfirmasi:

```
✅ Tiket Berhasil Dibuat!

Tiket Anda telah dibuat!

📍 Channel: #ticket-namaanda-1234

Langkah Selanjutnya:
1. Cek channel tiket untuk informasi pembayaran
2. Selesaikan pembayaran Anda
3. Tunggu verifikasi dari staff
4. Setelah disetujui, Anda akan mendapat akses ke chatroom server!

Terima kasih atas pembelian Anda! 🎉
```

---

## 💳 Proses Pembayaran

### Di Channel Tiket Anda
1. Channel baru akan dibuat: `#ticket-namaanda-xxxx`
2. Anda akan di-ping bersama staff
3. Tiket menampilkan:
   - 🖥️ Nomor server
   - 💰 Total harga
   - 👥 Jumlah slot
   - 📝 Username Roblox yang Anda berikan

### QR Code Pembayaran
- Bot akan mengirim **QR code pembayaran**
- Scan dan bayar sesuai jumlah yang ditampilkan
- Simpan bukti pembayaran (screenshot)

### Menunggu Persetujuan
- ⏳ Staff akan memverifikasi pembayaran Anda
- 🔔 Anda akan diberi tahu saat disetujui
- ⏱️ Biasanya memakan waktu 5-30 menit (tergantung ketersediaan staff)

---

## ✅ Setelah Disetujui

### Anda Akan Menerima:
1. 🎭 **Role server** - `Server X Member`
2. 💬 **Akses channel** - `server-X-chat`
3. 📢 **Notifikasi** di tiket Anda

### Pesan Persetujuan:
```
✅ Pembelian Disetujui

Pembelian Anda telah disetujui oleh @NamaStaff!

Anda sekarang memiliki akses ke #server-1-chat di mana Anda bisa chat dengan staff dan member lainnya.

Langkah Selanjutnya:
1. Tunggu sampai semua slot terisi (saat ini: 8/20)
2. Staff akan mengaktifkan boost
3. Tambahkan staff di in-game untuk bergabung ke server yang di-boost

Terima kasih atas pembelian Anda!
```

## ⚡ Aktivasi Boost

### Kapan Diaktifkan?
- Staff bisa mengaktifkan boost kapan saja
- Biasanya diaktifkan saat server penuh atau di waktu yang sudah dijadwalkan
- Anda akan di-ping saat itu terjadi!

### Pengumuman Aktivasi:
```
⚡ BOOST DIAKTIFKAN!

@Server 1 Member

Boost Server 1 sekarang aktif!
Semua member bisa bergabung ke server game untuk pengalaman boost x8.

⏰ Durasi: 6 jam
🕐 Dimulai: Hari ini jam 3:00 PM
🕐 Berakhir: Hari ini jam 9:00 PM
```

### Yang Harus Dilakukan:
1. 🎮 Bergabung ke game (staff akan memberikan detail)
2. 📲 Tambahkan staff di in-game untuk join server mereka
3. ⚡ Nikmati boost x8 selama durasi berlangsung!
4. 💬 Gunakan chatroom server untuk koordinasi

## ❌ Error Umum & Solusi

### "Server sudah penuh"
- **Masalah**: Orang lain mengisi slot terakhir
- **Solusi**: Coba server lain atau tunggu server baru

### "Anda perlu memberikan tepat X username"
- **Masalah**: Tidak cocok antara jumlah slot dan username
- **Solusi**: Hitung ulang username Anda (satu per baris)

### "Slot tidak tersedia"
- **Masalah**: Server terisi saat Anda membeli
- **Solusi**: Batalkan dan pilih server berbeda

### "Modal timeout"
- **Masalah**: Terlalu lama untuk submit
- **Solusi**: Mulai ulang dari dropdown

### Tiket tidak dibuat
- **Masalah**: Masalah konfigurasi bot
- **Solusi**: Hubungi staff untuk bantuan

## 🎯 Tips Pembelian

### Memilih Server
- 📊 Cek ketersediaan slot sebelum membeli
- ⚡ Server aktif = boost sudah berjalan
- ⏳ Server pending = menunggu aktivasi
- 💰 Bandingkan harga jika ada banyak server

### Jumlah Slot
- 🎮 1 slot = 1 akun Roblox
- 👥 Beli untuk teman? Dapatkan slot cukup untuk semua orang
- 💡 Lebih banyak slot = lebih banyak akun yang bisa benefit

### Waktu
- 🕐 Beli lebih awal untuk jamin tempat
- 📢 Perhatikan pengumuman tentang server baru
- ⚡ Gabung saat boost aktif untuk benefit langsung
