So I want to make a multipurpose bot for my store in discord

It will be a ticket bot with information displays and a room maker (channel) and role maker

Context: This discord server sell "slots" in a game for a x8 boost ingame
Example: 
I want to experience x8 boost in the game 
I purchase slot in the discord server
The seller add friend me in game so the buyer can join the seller ingame server with x8 boost

Feature 1

Ticket (Buyer Side)

Ticket panel using dropdown and modal
This dropdown auto updates
- Staff using command (example) /start server
- Bot automatically identifies the server number based on active servers starting from 1
Buyers choose the server from the dropdown list
After choosing which server, I'm not sure how the interaction chain should be but basically they tell the bot how many slots they are purchasing (1 slot = 1 account), and after that interaction, the user must fill Roblox name based on the stated slots. 
Example: They stated purchasing 6 slot, next interaction (idk what feature to use) they will type down 6 Roblox usernames to submit
After those interaction are done, send an embed with confirmation consisting the server information & Roblox usernames the user listed
Ticket channel is created after confirm button is pressed


Ticket (Seller Side)
After ticket is created, bot sends an approval embed with buttons in a staff only channel
In the ticket channel, bot pings staff role & user that created the channel with embed of server information & Roblox usernames
It also sends an image in embed which will be the payment embed (methods) and the image being QRIS (using media link, configured to the bot)
Once the staff verify the payment, they will go to the approval channel and press approve / decline which will if approved, gives the user a role to access the server chatroom
Example
Buyer purchase got approved (server 1)
Bot gives a specific role to user (server 1 role)
The role has chat access to the server chat room (server 1 chat room)
Seller can communicate with the buyer in that specific channel (server 1 buyers and seller)
Applies to server 2, 3, and so on
