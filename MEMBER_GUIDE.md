# 🎮 Member Guide - How to Purchase Server Slots

## Welcome!
This guide will help you purchase server slots and join boosted game servers through our Discord bot.

---

## 🛒 How to Purchase Slots

### Step 1: Find the Member Panel
Look for the **Member Panel** message in your designated purchase channel. It looks like this:

```
🛒 Member Panel
━━━━━━━━━━━━━━━━━━━━━

Use the dropdowns below to purchase slots or view server information.

Purchase Slots: Select a server to buy slots
Server Info: View details and member list
```

---

### Step 2: Select a Server
Click the **"🛒 Purchase Slots"** dropdown and choose a server.

**What you'll see:**
- Server 1 - X/20 slots | IDR 20,000 | Pending/Active

**Legend:**
- **X/20 slots**: How many slots are filled (max 20)
- **IDR 20,000**: Price per slot
- **Pending**: Boost not activated yet
- **Active**: Boost is currently running

---

### Step 3: Enter Slot Count
After selecting a server, you'll see a modal (popup):

```
📝 How Many Slots?
━━━━━━━━━━━━━━━━━━━━━

Enter the number of slots you want to purchase (1-20)
```

**Enter a number** between 1 and the available slots.

**Example:**
- If server shows **5/20**, you can buy up to **15 slots**
- Enter `3` to buy 3 slots

Click **Submit**

---

### Step 4: Enter Roblox Usernames
Next, you'll see another modal:

```
📝 Enter 3 Roblox Usernames
━━━━━━━━━━━━━━━━━━━━━

Enter 3 username(s) (one per line)
```

**Important:**
- Enter **exactly** the number of usernames you specified
- One username per line
- Use exact Roblox usernames (case-sensitive)

**Example:**
```
PlayerOne
CoolGamer123
ProPlayer99
```

Click **Submit**

---

### Step 5: Confirm Purchase
You'll see a confirmation message with:

```
📝 Confirm Your Purchase

You've selected 3 slot(s) for Server 1.

Server: Server 1
Price per slot: IDR 20,000
Total: IDR 60,000

You'll need to provide 3 Roblox username(s)
```

**Review carefully, then click:**
- ✅ **Confirm** - Proceed with purchase
- ❌ **Cancel** - Cancel and start over

---

### Step 6: Ticket Created! 🎉
After confirmation:

```
✅ Ticket Created Successfully!

Your ticket has been created!

📍 Channel: #ticket-yourname-1234

Next Steps:
1. Check the ticket channel for payment information
2. Complete your payment
3. Wait for staff verification
4. Once approved, you'll get access to the server chatroom!

Thank you for your purchase! 🎉
```

---

## 💳 Payment Process

### In Your Ticket Channel
1. A new channel will be created: `#ticket-yourname-xxxx`
2. You'll be pinged along with staff
3. The ticket shows:
   - 🖥️ Server number
   - 💰 Total price
   - 👥 Slot count
   - 📝 Roblox usernames you provided

### Payment QR Code
- The bot will post a **payment QR code**
- Scan and pay the exact amount shown
- Keep proof of payment (screenshot)

### Waiting for Approval
- ⏳ Staff will verify your payment
- 🔔 You'll be notified when approved
- ⏱️ Usually takes 5-30 minutes (depending on staff availability)

---

## ❌ Common Errors & Solutions

### "Server is now full"
- **Problem**: Someone else filled the last slots
- **Solution**: Try another server or wait for new server

### "You need to provide exactly X usernames"
- **Problem**: Mismatch between slot count and usernames
- **Solution**: Count your usernames again (one per line)

### "Slots not available"
- **Problem**: Server filled up during your purchase
- **Solution**: Cancel and select a different server

### "Modal timed out"
- **Problem**: Took too long to submit
- **Solution**: Start over from the dropdown

### Ticket not created
- **Problem**: Bot configuration issue
- **Solution**: Contact staff for help
